Designed for review

Make every alert traceable

Each finding retains the records and observed values behind its rule. Candidate mappings and anomaly scores remain hypotheses until a person checks the context.

SIGNALS

Explainable rules

Port diversity, unusually large transfers, host baselines, and periodic connection timing.

STORIES

Evidence correlation

Join related findings by endpoints and event windows; inspect a bounded host graph when the optional extra is installed.

BOUNDARIES

Local by default

Loopback API, per-run analyst token, append-only audit chain, and no live capture or response control.

Try it locally

A small, reproducible lab

Python 3.11+; optional public-data evaluation, host graphs, and LLM-assisted reports are clearly separated from the offline sample. A seeded generator creates 600 synthetic records with benign and labeled lab scenarios. Generated records stay out of Git.

python -m pip install -e ".[dev]"
python scripts/generate_sample_data.py
python -m sentinelmesh.cli analyze
python -m sentinelmesh.cli serve

Safety note
SentinelMesh is an educational defensive prototype. Synthetic signals are not real-world detection results, ATT&CK tags are contextual candidates, and simulated actions never change a network.

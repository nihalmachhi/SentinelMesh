# Flow data contract

Input is a JSON array. Each item requires `flow_id`, `timestamp`, `src_ip`, `dst_ip`, `src_port`, `dst_port`, `protocol`, `duration_ms`, `packets`, and `bytes_sent`. Optional `direction` is one of `inbound`, `outbound`, or `internal`.

```json
{
  "flow_id": "sample-00001",
  "timestamp": "2025-01-01T00:00:01Z",
  "src_ip": "10.20.0.1",
  "dst_ip": "198.51.100.1",
  "src_port": 51200,
  "dst_port": 443,
  "protocol": "TCP",
  "duration_ms": 300,
  "packets": 10,
  "bytes_sent": 1200,
  "direction": "outbound"
}
```

Allowed protocols are TCP, UDP, and ICMP. Addresses are parsed by Python's `ipaddress` module. A file is capped at 2 MB and 20,000 records; IDs must be unique per import. Unknown object keys, naive timestamps, payload bytes, and raw packet contents are not accepted. Valid timestamps are normalized to UTC.

## Sample provenance

`data/generated/sample_flows.json` is generated by `scripts/generate_sample_data.py` using Python's seeded standard-library random generator. It contains no copied third-party dataset, real user traffic, or external feed. The fixture is synthetic, ignored by Git, and has no third-party dataset licence or redistribution terms. Regenerate the canonical 600-row file with:

```bash
python scripts/generate_sample_data.py --count 600 --seed 41
```

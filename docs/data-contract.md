# Flow data contract

Input is a JSON array. Each item requires `flow_id`, `timestamp`, `src_ip`, `dst_ip`, `src_port`, `dst_port`, `protocol`, `duration_ms`, `packets`, and `bytes_sent`. Optional `direction` is one of `inbound`, `outbound`, `internal`, or `unknown`. Unknown means direction was not safely inferable and is excluded from direction-sensitive rules.

```json
{
  "flow_id": "sample-00001",
  "timestamp": "2025-01-01T00:00:01Z",
  "src_ip": "10.20.0.1",
  "dst_ip": "198.51.100.1",
  "src_port": 51200,
  "dst_port": 443,
  "protocol": "TCP",
  "duration_ms": 300,
  "packets": 10,
  "bytes_sent": 1200,
  "direction": "outbound"
}
```

Allowed protocols are TCP, UDP, and ICMP. Addresses are parsed by Python's `ipaddress` module. A file is capped at 2 MB and 20,000 records; IDs must be unique per import. Unknown object keys, naive timestamps, payload bytes, and raw packet contents are not accepted. Valid timestamps are normalized to UTC.

## Sample provenance

`data/samples/sample_flows.json` is generated by `scripts/generate_sample_data.py` using Python's seeded standard-library random generator. It contains no copied third-party dataset, real user traffic, or external feed. `scenario_labels.csv` records benign, port-scan, large-egress, repeated-SSH, and beaconing examples separately from the strict flow schema. The fixture and its labels are synthetic, ignored by Git, and have no third-party dataset licence or redistribution terms. Regenerate the canonical 600-row file with:

```bash
python scripts/generate_sample_data.py --count 600 --seed 41
```

## Optional Zeek conn.log input

Use `sentinelmesh analyze --input path/to/conn.log --format zeek-conn` to read Zeek tab-separated connection metadata with a `#fields` header. The adapter maps originator bytes and total observed packets into the shared flow contract, converts Unix seconds to UTC, and derives direction only when one or both endpoints use RFC1918 or IPv6 ULA space. Other public-to-public flows are labeled `unknown`; detection rules do not treat unknown direction as outbound. The file remains subject to the same 2 MB and 20,000-row bounds. Do not upload packet payloads or logs you are not authorized to analyze.

## NetFlow/IPFIX-derived CSV

Use `sentinelmesh analyze --input flows.csv --format netflow-csv` for a normalized CSV with columns `timestamp`, `src_ip`, `dst_ip`, `src_port`, `dst_port`, `protocol`, `duration_ms`, `packets`, and `bytes_sent`. Timestamps must already include a timezone. Common aliases such as `srcaddr`, `dstaddr`, `sport`, `dport`, `proto`, `in_bytes`, and `in_pkts` are accepted. This is a documented normalized interchange schema; NetFlow/IPFIX exporter-specific binary formats are not parsed.

For an offline PCAP conversion, install Zeek separately and run `zeek -r capture.pcap` in a dedicated working directory, then pass the resulting `conn.log` with `--format zeek-conn`. SentinelMesh never opens a live capture interface.

# Threat model

## Scope

SentinelMesh is a local educational network-flow investigation demo. It accepts prepared JSON, derives explainable findings, stores them in a local SQLite file, serves a dashboard on loopback, and records simulated analyst decisions. It is not a production detection or response platform.

## Assets

- Integrity and provenance of imported flow records.
- Integrity of reports, approvals, and append-only audit history.
- The random per-run API bearer token.
- The local database and analyst browser session.

## Threats and controls

| Threat | Control | Remaining limit |
| --- | --- | --- |
| Malformed or oversized flow input | 2 MB and 20,000-row bounds, strict JSON schema, address/protocol/counter validation | The application does not parse arbitrary packet captures |
| Browser-originated unauthorized writes | Random token, same-origin checks, loopback host checks, CSP and frame/content headers | A local machine compromise or token disclosure is out of scope |
| Audit history modification through application code | Append-only triggers and SHA-256 hash chain verification | A local administrator able to replace the database and code can bypass application-level controls |
| Prompt/tool misuse | Fixed tool allowlist over local read-only evidence; no shell or external model | Reports may still be incomplete or misleading; human review is required |
| Misinterpreting rules as proof | Findings retain evidence IDs and are labeled as triage hypotheses | No real-world false-positive or efficacy evaluation is available |
| Accidental real-world response | Actions are recorded as simulated-only; no control integration exists | Users must not expose the demo as an operational response service |

## Safe operation

Bind only to `127.0.0.1`, keep the startup token private, use benign data from an owned or appropriately licensed lab, and back up the local database before manual maintenance. The bundled records are generated by the repository and use reserved/private example address ranges. They are not an external dataset and have no third-party licence terms.

## Reporting

This repository is a non-production demonstration. Report suspected security issues through the repository owner’s private contact channel; do not include sensitive traffic captures in public issues.
